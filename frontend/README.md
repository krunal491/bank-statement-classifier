# Frontend

React (Vite) UI for the bank statement classifier. Talks to the FastAPI backend in `../backend`.

```bash
npm install
npm run dev      # dev server on :5173, proxies /api to localhost:8000
npm run build    # production build -> dist/ (served by the FastAPI backend)
```

See the repo root [README](../README.md) for the full setup (backend, Tesseract, deploy).
